Featured Project

MediBook

Purpose: Streamline healthcare access by connecting patients with trusted specialists through an intuitive booking system, while providing doctors and administrators with powerful management tools.

Technologies Used: Node.js, Express, MongoDB, Mongoose, HTML5, CSS3, JavaScript (ES6), JWT Authentication, REST API.

Key Features:
  • Patient booking wizard with real-time availability
  • Doctor dashboard (schedule, patient management, availability)
  • Admin dashboard (user management, analytics, system settings)
  • Secure authentication with role-based access control (patient, doctor, admin)
  • Responsive design with dark mode
  • Multi-language support
  • Real-time appointment updates

Challenges Solved: Building a scalable role-based architecture, implementing secure JWT authentication, designing a responsive and accessible interface, integrating real-time data synchronization across patient, doctor, and admin views, and building a multi-step booking wizard with validation.
